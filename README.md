# Week 1: Personal Introduction Program

## Project Overview
This program collects user information (name, age, hobby, city, GPA) and displays a personalized welcome message with emojis. The goal is to practice Python fundamentals including variables, input/output, f-strings, and functions.

## Setup Instructions
1. Ensure Python 3.x is installed on your system
2. Download or clone this repository
3. Navigate to the project folder
4. Run the program using: `python personal_intro.py`


## Technical Details
- **Algorithm:** Sequential execution
- **Data Structures:** Variables (string, integer, float)
- **Key Functions:** input(), print(), f-strings
- **Architecture:** Single main() function
