# Week 1: Personal Introduction Program

## Project Overview
A Python program that collects user information (name, age, hobby, city, GPA) and displays a personalized welcome message with emojis.

## Setup Instructions
1. Ensure Python 3.x is installed on your system
2. Download or clone this repository
3. Navigate to the project folder
4. Run the program using the command below

## How to Run
```bash
python personal_intro.py
